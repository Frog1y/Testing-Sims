# Zabbix

<img width="2500" height="655" alt="image" src="https://github.com/user-attachments/assets/dcea41f2-08cd-4b83-9e7f-fdba03543d10" />

Zabbix is an enterprise-class, open-source IT infrastructure monitoring solution.\
It tracks performance, detects problems, sends alerts and visualizes monitoring data.\
It can be configured to monitor almost any IT device or virtual entity.
